# Safe Abroad&#x20;

**A Smart Mobile Application for Safe Foreign Employment**

## About the Project

Safe Abroad is a Flutter-based mobile application designed to help Sri Lankan citizens make safer and more informed decisions before travelling abroad for employment.

The application provides useful information and tools to help users check foreign employment agencies, explore destination countries, understand worker rights, and access important safety information.

## Main Features

- **Agency Checker:** Search foreign employment agencies by name or license number.
- **Agency Status:** View agency registration statuses such as Licensed, Suspended, and Cancelled.
- **Country Guide:** Explore useful information about foreign employment destinations.
- **Worker Rights:** Learn about the basic rights and responsibilities of overseas workers.
- **Travel Checklist:** Prepare important documents and items before travelling.
- **Emergency Contacts:** Access important emergency contact information.
- **Family Contacts:** Save important family contact details.
- **SOS Support:** Access emergency support features.
- **OTP Login:** Sign in using a phone number and OTP verification.
- **Guest Access:** Explore selected application features without logging in.

## Installation

1. Clone the repository.

```bash
git clone https://github.com/nimesha1234455/safe-abroad.git
```

2. Navigate to the project folder.

```bash
cd safe-abroad
```

3. Install dependencies.

```bash
flutter pub get
```

4. Run the application.

```bash
flutter run
```

## Project Purpose

The main purpose of Safe Abroad is to support Sri Lankan citizens by providing useful information and safety-related services before and during overseas employment.

**Note:** Agency information should be verified using official SLBFE sources. Application information is provided for guidance and does not replace official government confirmation.
